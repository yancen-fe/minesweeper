# 经典扫雷

支持网页、Windows 和 macOS 的扫雷游戏。对局和战绩保存在本机，可用分享码跨设备挑战同一张雷区或继续对局。

## 玩法

翻开所有没有地雷的格子即可获胜，翻到地雷则本局结束。数字表示周围八格中的地雷数，空白格会自动展开。首个翻开的格子及其相邻格保证安全。

| 难度 | 棋盘（行 × 列） | 地雷 |
| --- | --- | ---: |
| 初级 | 9 × 9 | 10 |
| 中级 | 16 × 16 | 40 |
| 专家 | 16 × 30 | 99 |

- **经典随机**（默认）可能遇到需要猜测的局面。
- **无猜**会为首步生成一张可用逻辑推理完整解开的雷区。
- 切换难度或玩法会开一局新棋；点击笑脸可重开，点击「暂停」可停止计时。

## 操作

| 操作 | 方法 |
| --- | --- |
| 翻格 | 鼠标左键或触屏点按。键盘用方向键移动，再按空格或 Enter。 |
| 标记 | 鼠标右键或按 F，依次切换旗帜、问号和未标记。手机先开启「插旗模式」，再点格子。 |
| 快速展开 | 当一个已翻开的数字周围旗帜数量与数字相符时，点击该数字可翻开剩余邻格。插错旗仍可能踩雷。 |

问号只用于提醒，不占用旗帜名额，也不参与快速展开的旗帜计数。

## 分享与战绩

翻开第一格后，从右上角菜单选择「分享本局」。

- **复制本局挑战**保留雷区与首步位置，接收方从零开始计时。
- **复制当前进度**还会保留翻开的格子、旗帜、问号和用时，适用于进行中的对局。
- 接收方在「导入对局」粘贴分享码并读取预览，再选择「从头挑战」或「继续进度」。

菜单里的「历史记录」可按难度、玩法、结果和日期筛选战绩，并查看胜率和最佳用时。

## 本地运行

从仓库根目录执行以下命令，然后打开 [本地网页版](http://127.0.0.1:5173/)。

```sh
npm --prefix desktop ci
npm --prefix web start
```

- **Windows 桌面版**需要 Node.js、Rust 和 Tauri 的 Windows 构建依赖。安装 npm 依赖后，运行 `npm --prefix desktop run tauri -- dev`。
- **macOS 原生版**需要 Apple Silicon、macOS 14 或更高版本，以及 Xcode 或带 macOS SDK 的 Swift 工具链。在仓库根目录运行 `bash native/scripts/build-app.sh`，再打开 `dist/扫雷.app`。
- **自动测试**运行 `npm --prefix desktop test`。
